## 1.1 The line and its two symbols

The output is the [[a]] times the [[x]]. With a slope of {{inputs.a|int}} and an input of {{inputs.x|int}}, the output is {{outputs.y|int}}. A line like this, where the output is always the same multiple of the input, is a proportional relation. If each unit of output were sold at {{params.unit_price|sum}}, the {{outputs.y|int}} units would bring in a sum the reader can work out in one step.

```eq
id: 1.1
code: engine.js y
title: The output of the line
meaning: The output is the slope times the input, so it doubles when the input doubles.
numbers: {{outputs.y|int}} = {{inputs.a|int}} \times {{inputs.x|int}}
symbols: y = \underbrace{a}_{\text{slope}} \times \underbrace{x}_{\text{input}}
```

## 1.2 Solving the line for the input

Going the other way, from a known output back to the input, takes one division.

```steps
id: 1.2
title: From the output back to the input
y = a x // start from the line
\frac{y}{a} = x // divide both sides by the slope
x = \frac{{{outputs.y|int}}}{{{inputs.a|int}}} = {{inputs.x|int}} // put in the numbers
```
